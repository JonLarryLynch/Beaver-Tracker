🦫 Wildlife Watch · Import historical sightings

This moderator tool loads real past observations from iNaturalist, GBIF or eBird into the map, so it starts with real data instead of an empty park. It isn’t part of the public site.

1. Get a CSV export

The easiest source is iNaturalist. Go to inaturalist.org/observations/export, filter to a place around Lincoln Park (or draw a box), and make sure these columns are ticked: license, user_login, user_name, url, quality_grade, coordinates_obscured. iNaturalist emails a download link, usually within minutes.

GBIF.org and eBird’s data downloads work too. Rows outside the park are skipped automatically.

3. Import

Each record is tagged as an import and keeps its source link, license and observer name, which the app shows as credit on the sighting. Photos and observers’ written descriptions are never copied. Running this twice on the same file won’t create duplicates.

Sign in with the same Google account you use on admin.html.

About attribution. Most iNaturalist and GBIF records use Creative Commons licenses that ask for credit to the observer. That’s why each imported sighting keeps the observer’s name, the license and a link back to the original. eBird data comes with its own terms of use, which ask for credit and non-commercial use.
